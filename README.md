# English Skills — GitHub Pages

Reading, Speaking, Listening, Writing және English Grammar бөлімдері бар дайын статикалық сайт. Бастапқы оқу материалдары сақталды. Reading бөлімі 1–11, қалған дағды бөлімдері 3–11 сыныптарға арналған.

## GitHub-қа жүктеу

1. ZIP архивін компьютерде ашыңыз.
2. Репозиторийде Add file → Upload files таңдаңыз.
3. Осы архивтің ішіндегі барлық файлды репозиторийдің түбіріне жүктеңіз. ZIP файлының өзін немесе сыртқы папканы жүктемеңіз. index.html файлдар тізімінде бірден көрінуі керек.
4. Commit changes басыңыз.
5. Settings → Pages → Build and deployment: Source = Deploy from a branch.
6. Branch = main (не файлдар жүктелген тармақ), Folder = / (root), Save.
7. Жариялау аяқталғаннан кейін Pages бөліміндегі сайт сілтемесін ашыңыз.

Ескі index (1).html басты бетін index.html алмастырады. Файл атауларының үлкен/кіші әріптерін өзгертпеңіз. Сілтемелер репозиторий атауына тәуелсіз салыстырмалы жолдарды қолданады.

## Қолдану

Компьютерде index.html файлын браузермен ашыңыз. Сервер, npm немесе API кілті қажет емес. JavaScript қосулы болсын. Жауаптар осы браузерде сақталады; басқа құрылғыға автоматты көшірілмейді.

Listening браузердің мәтінді дыбыстау мүмкіндігін қолданады: ағылшын дауысының қолжетімділігі браузер мен құрылғыға байланысты, кейбір дауыстар интернетті қажет етуі мүмкін. Speaking бөліміндегі дыбыс жазу үшін микрофон рұқсаты және HTTPS (GitHub Pages) немесе localhost қажет болуы мүмкін.
